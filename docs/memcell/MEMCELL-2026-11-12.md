### The deck that was read: "DREAMCHAMBER / MC96 Sovereign Command Operating System v2.0" (50 slides)

**Thesis (slides 1-4):** an operating system for human intent, not a chatbot. "Human control is the product."
A spoken request becomes a visible plan, an explicit approval, a bounded action, and a signed proof.

**Act 1, Control (5-11):**
- **Rule Zero:** one human-approved command → one immutable plan hash → one terminal receipt.
- Separation of powers: no interface, agent, connector or model gets ambient authority.
- Command state machine: received → validated → planned → awaiting approval → queued → running → terminal.

**Act 2, Trust (8-22):**
- Canonical actor RSP_001, rooted in a passkey and hardware key (not a GitHub login alone).
- Five proofs before execution: identity, intent, policy, approval, capability.
- Command envelope v2 and receipt envelope v2; request, trace, correlation and idempotency ids are different things.
- **Four risk classes:** R0 read (automatic) · R1 reversible · R2 material · R3 irreversible (deliberate friction).
- Policy as code, "not personality as permission". Approval is a signed, expiring token bound to the plan hash.
- Replay defence (timestamp, nonce, signature), separate keys per purpose, a threat model that assumes stolen tokens,
  ambiguous speech, crashes and operator fatigue.

**Act 3, Voice-first control (23-36):**
- "Accessibility is not an add-on. It is the operator architecture."
- Local-first voice: capture → whisper.cpp → strict lexicon → preview. Confidence zones: ≥0.90 preview; 0.72-0.89 ask
  one question; below that, never guess.
- Every surface (Shortcuts, Warp, Xcode, Slack, Discord, agents) calls **one command contract**. No side doors.
- Connectors translate; they never become identity or policy. Streaming and studio (OBS, Audio Hijack, SonoBus,
  Loopback, BlackHole, Logic) are coordinated, never in the audio path.
- Durable execution with a transactional inbox and outbox ("no Kafka, no mystery"); a failure taxonomy with retry rules.

**Act 4, Observability and proof (37-42):**
- One command becomes one trace. Append-only receipts in a hash chain with a daily root.
- Redaction and retention are part of the schema. The Hub is read-only, high-contrast, voice-navigable, built on exceptions.
- Measure trust: success rate, preview accuracy, time to understand, recovery.

**Act 5, Launch (43-50):**
- The AI family become bounded roles: GABRIEL explains policy and does not execute; LUCY is R0/R1 only by default.
- CI gates: lint, tests, security scan, SBOM, signed builds. An acceptance suite of end-to-end proofs.
- 30 days: the smallest complete command spine, one domain. 90 days: generalize, then harden.
- Closing line: "We are not automating chaos. We are restoring human control."

**How today's builds line up with it:** NOIZYBRIDGE (fixed verbs, key, HALT) is a first, simple "one command contract";
NOIZYBOTS, the Siri intents and the Warp jobs all call it; receipts exist as a log, not yet a hash chain;
risk classes and signed approvals are **not built**.
